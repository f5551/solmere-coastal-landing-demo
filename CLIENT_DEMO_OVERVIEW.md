# Solmere — Client Demo Overview

## Purpose

Solmere is a simple, independent, working coastal-residential website concept demo inspired by the requirements in the client's Upwork job. It showcases a responsive page layout, polished visual presentation, and common interactive features. **It is not the client's original design, final website, an approved property listing, or a representation of a verified development.**

The client has not supplied the original design files, approved property imagery, final branding, verified property information, or production email destination. The page therefore uses clearly identified sample photography, concept copy, conceptual map artwork, and temporary branding.

## What the demo demonstrates

- A full-width image-led hero with transparent navigation and mobile menu.
- Editorial content and large image presentation.
- An illustrative map with a responsive, conceptual site-boundary overlay.
- A lifestyle selector that changes the image and description.
- An interiors carousel with centered slides, neighboring slides, controls, and keyboard interaction.
- A responsive, accessible enquiry form experience in Demo Mode.

## Form and privacy status

The enquiry form is **in Demo Mode**. It performs front-end validation and displays a demo confirmation only. It does not submit information to an email address, send it to a backend, or store the entered details. The optional serverless handler is included as inactive source code and is not a configured delivery service. Do not enter real personal information in the demo.
